Welcome to my OASIS INFOBYTE Python Programming Internship repository! This repository contains the Python projects I developed during my internship to strengthen my programming, problem-solving, and application development skills.

📌 About the Internship

The internship provided an opportunity to apply Python concepts by developing practical applications, exploring libraries, integrating APIs, and building useful tools.

🚀 Projects

1. 🎙️ Voice Assistant

A Python-based voice assistant designed to recognize spoken commands and perform useful tasks.

Features

- Speech recognition and voice responses
- Current time and date information
- Web searches and browser interaction
- Weather information using an API
- Email functionality using SMTP
- Basic Natural Language Processing (NLP)
- Wikipedia-based information retrieval
- Reminder functionality

Technologies: Python, SpeechRecognition, pyttsx3, NLTK, APIs, SMTP

2. 🧮 BMI Calculator

A Python application that calculates Body Mass Index (BMI) using the user's height and weight.

Features

- BMI calculation
- User input validation
- BMI result and category display
- Calculation history, where implemented

Technologies: Python, Tkinter

3. 🔐 Random Password Generator

A Python application for generating secure random passwords with customizable options.

Features

- Generate random passwords
- Customize password length
- Include different character types
- Password strength indicator
- Copy generated passwords to the clipboard
- Password history, where implemented

Technologies: Python, Tkinter, "secrets", "pyperclip"

⚙️ Installation and Usage

Prerequisites

- Python 3.10 or later, depending on project requirements
- Git
- Required libraries for each project

Clone the Repository

git clone https://github.com/FarazMemon004/OIBSIP.git
cd OIBSIP/Python

Run a Project

Navigate to the required project directory and run its Python entry-point file.

For example:

cd "Task2-BMICalculator"
python main.py

Install the dependencies required by each project before running it. If a project includes a "requirements.txt" file, use:

python -m pip install -r requirements.txt
